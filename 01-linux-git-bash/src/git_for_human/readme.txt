Практика работы с Git — типичный workflow для учебного репозитория:

1. Создай ветку develop и веди в ней основную работу.
2. От develop создай ветку key-branch. Убедись, что в ней есть файл main.key.
3. Создай копию ключа (main-2.key) и зафиксируй изменения коммитом.
4. Создай ветку feature/3-key от key-branch.
5. Создай вторую копию ключа (main-3.key) в ветке feature/3-key и закоммить.
   В начале сообщения коммита укажи имя ветки.
6. Влей изменения из feature/3-key в key-branch (merge).
7. Создай ветку release/1.0 от develop.
8. Последовательно влей key-branch в develop, затем develop в release/1.0.

Все исходники храни в каталоге src/.
