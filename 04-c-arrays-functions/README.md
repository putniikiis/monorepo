# 04 — Массивы и функции в C

Работа с одномерными массивами, передача параметров по указателю, базовая статистика.

## Программы

| Файл | Задача |
|------|--------|
| `maxmin.c` | Минимум и максимум из трёх целых |
| `squaring.c` | Возведение элементов массива в квадрат |
| `stat.c` | Сортировка массива, min, max, среднее, дисперсия |
| `search.c` | Поиск элемента по статистическим критериям |

## Сборка

```bash
cd src
gcc -std=c11 -Wall -lm -o maxmin maxmin.c
gcc -std=c11 -Wall -lm -o stat stat.c
gcc -std=c11 -Wall -lm -o search search.c
```

Для `search.c` и `stat.c` нужна библиотека математики: флаг `-lm`.

## Примеры

**maxmin.c** — три целых:
```
1 5 3
```
Вывод: `5 1`

**search.c** — сначала длина `n`, затем `n` целых. Возвращает первый элемент, удовлетворяющий условиям (чётный, ≥ среднего, в пределах 3σ), или `0`.

## Навыки

- Массивы фиксированного размера
- Указатели как параметры функций
- `math.h`: `sqrt`, `pow`
