# 03 — Основы языка C

Первые программы на C: стандартный ввод/вывод, функции, целочисленная и вещественная арифметика.

## Программы

| Файл | Задача |
|------|--------|
| `hello.c` | Вывод приветствия |
| `named_hello.c` | Персонализированное приветствие |
| `arithmetic.c` | Сложение, вычитание, умножение, деление двух целых |
| `max.c` | Максимум из трёх чисел |
| `important_function.c` | Вычисление по формуле |
| `float_compare.c` | Сравнение чисел с плавающей точкой |
| `crack.c` | Проверка попадания точки в область (круг) |

## Сборка и запуск

```bash
cd src
gcc -std=c11 -Wall -o hello hello.c && ./hello
gcc -std=c11 -Wall -o arithmetic arithmetic.c && ./arithmetic
```

## Примеры ввода

**arithmetic.c** — два целых через пробел:
```
5 3
```
Вывод: `8 2 15 1` (сумма, разность, произведение, частное)

**crack.c** — координаты `x y`:
```
3.0 4.0
```
Вывод: `GOTCHA` если `x² + y² < 25`, иначе `MISS`
