# 02 — Shell-скрипты и Vim

Продолжение работы в терминале: анализ логов, редактирование файлов и знакомство с Vim.

## Что внутри

| Файл | Описание |
|------|----------|
| `log_analyzer.sh` | Анализ лог-файла: число строк, уникальных полей, хешей |
| `edit.sh` | Скрипт редактирования |
| `files.log` | Пример лог-файла для анализа |
| `history_of_vi.txt` | Краткая история редактора vi |
| `history_of_vim.txt` | Краткая история Vim |

## Навыки

- Чтение аргументов и ввода пользователя (`read`)
- Конвейеры: `cat`, `wc`, `awk`, `sort`, `uniq`
- Работа с текстовым редактором Vim

## Запуск

```bash
cd src
chmod +x log_analyzer.sh
./log_analyzer.sh
# Ввести путь к files.log при запросе
```

Пример вывода для `files.log`:

```
<number_of_lines> <unique_first_fields> <unique_hashes>
```
