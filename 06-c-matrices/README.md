# 06 — Матрицы и линейная алгебра

Двумерные массивы, определитель, обратная матрица, системы линейных уравнений, сортировки матриц.

## Программы

| Файл | Задача |
|------|--------|
| `det.c` | Определитель квадратной матрицы |
| `invert.c` | Обратная матрица (метод Гаусса) |
| `sle.c` | Система линейных уравнений |
| `electro_snake.c` | Сортировки матрицы: по столбцам, строкам, спирали |

## Сборка

```bash
cd src
gcc -std=c11 -Wall -o det det.c
gcc -std=c11 -Wall -o invert invert.c
gcc -std=c11 -Wall -lm -o electro_snake electro_snake.c
```

## Примеры

**det.c** — размер `n`, затем `n×n` элементов:
```
3
1 2 3
4 5 6
7 8 9
```

**invert.c** — размер и элементы квадратной матрицы; выводит обратную или `n/a`.

## Навыки

- Динамическое выделение памяти (`malloc` / `free`)
- Рекурсивный расчёт определителя
- Метод Гаусса для обратной матрицы
- Преобразования и сортировки 2D-данных
