# 07 — Библиотека строк на C

Реализация базовых строковых функций без использования `string.h`.

## API

| Функция | Аналог | Описание |
|---------|--------|----------|
| `my_strlen` | `strlen` | Длина строки |
| `my_strcmp` | `strcmp` | Лексикографическое сравнение |
| `my_strcpy` | `strcpy` | Копирование строки |
| `my_strcat` | `strcat` | Конкатенация |
| `my_strchr` | `strchr` | Поиск символа |
| `my_strstr` | `strstr` | Поиск подстроки |
| `my_strtok` | `strtok` | Разбиение по разделителям |

## Структура

```
src/
├── my_string.h      # Заголовок
├── my_string.c      # Реализация
├── my_string_test.c # Тесты
└── Makefile
```

## Сборка и тесты

```bash
cd src
make strlen_tests    # тест my_strlen
make strcmp_tests    # тест my_strcmp
make all             # все тесты
make clean
```

Исполняемые файлы собираются в `build/` (создайте каталог при необходимости: `mkdir -p build`).

## Навыки

- Работа с указателями и нуль-терминированными строками
- Реализация стандартных алгоритмов вручную
- Модульные тесты через препроцессор (`-D TEST_STRLEN` и т.д.)
